Emacs config: A (this repo) vs B (zHaOdANiuu)

Source: docs/research/emacs-config-comparison-zhaodaniuu.md. Read from source only. Neither config was run.

Two designs

A: this repo

  • About 100 modules in lisp/
  • Hel modal editing + SPC leader
  • vertico + consult + corfu
  • projectile, org-gtd, denote, AI tools
  • Mostly eager require

B: zHaOdANiuu

  • 11 modules in user-lisp/
  • No modal package; CUA-like keys + F-keys
  • Built-in fido + corfu
  • Built-in project.el, apheleia, citre, dape
  • Lazy: always-defer + first-input/first-file hooks
